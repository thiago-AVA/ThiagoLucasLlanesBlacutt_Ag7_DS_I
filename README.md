# Classificação de Consumo de Água
 Objetivo do projeto

Este projeto consiste em um script desenvolvido em Python para classificar o perfil de consumo de água de um imóvel e apresentar uma mensagem educativa de acordo com o tipo de imóvel e o consumo mensal informado.

Ele trabalha principalmente com If, elif e else e operadores lógicos.

# como usar
Ensira o nome do imóvel, e a quantidade de agua gasta em metro cúbico.
